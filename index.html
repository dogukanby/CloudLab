MODULE 00

What Is "The Cloud," Really?

When you save a photo, send a message, or stream a video, it usually doesn't stay on your phone or laptop.

It didn't used to work this way.

Every cloud provider is really just selling four promises.

Each module below simulates one small piece of how that actually works.

A few words you'll see a lot below

Region
A specific geographic area a provider operates in.
Availability zone
One physically separate data center within a region.
Instance
A single rented virtual computer.
API
The set of rules a piece of software exposes.
Managed service
A piece of infrastructure the provider runs for you.
SLA / uptime
A provider's written promise for how reliable a service will be.
